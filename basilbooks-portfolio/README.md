# BasilBooks Legacy

BasilBooks is a book-community interface designed around discovery, personal shelves, reading goals, social activity, author workflows and administrator tooling. This curated snapshot focuses on the most complete React Admin implementation rather than every archived milestone.

![BasilBooks home-page design](./docs/screenshots/basilbooks-home.jpg)

## What this project demonstrates

- Multi-role product and interface design
- React Admin resource modelling
- Material UI component composition
- Navigation, filtering, settings and administrative workflows
- Translating wireframes into a working frontend

## Technology

- React 18 and Vite
- React Admin, Material UI and Emotion
- React Router
- TrailBase provider experiments

## Run locally

```bash
cd app
npm install
npm run dev
```

Open the local URL printed by Vite. The application is a historical prototype and some data-backed views may require the original service or mock-data adjustments.
